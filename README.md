**完美复刻蒸馏技能**是一个写作风格复刻技能，跑在 [WorkBuddy](https://www.workbuddy.cn) 里。给它某个作者的多篇文章，它用**双引擎蒸馏**，生成一个可安装的「写作分身」——分身写出来的东西，像到骨子里。

## ✨ 双引擎，怎么个"像"法

### 🧠 思维引擎
提取作者的**价值观、世界观、思维习惯**——先想得一样，才写得一样。

### ✍️ 写作引擎
提取词汇、句式、篇章、修辞等 **7+1 维写作风格**，含第 9 维思维框架分析。

### 🛡️ 双重复检系统（过不了闸不许输出）

| 复检 | 查什么 |
|---|---|
| **复检一 · 文风指纹** | 词汇 / 句式 / 结构 / 修辞 / 情感 / 视角 / 语气 |
| **复检二 · 思想一致性** | 立场 / 情绪 / 论证 / 身份 / 禁忌 |

### 📐 14 种写作公式内置
PAS、SCAR、QUEST、AIDA……分身写作时强制套用，出口即成品。

## 🎯 适用场景

- 你有喜欢的作者的多篇文章，想"复制"他的写作能力
- 你想分析为什么某人的文章读起来有辨识度
- 团队要统一多个写手的输出风格
- 给自己造一个"文风分身"，批量保持同一腔调
